通用資料擷取 — 書籤指令

把下面這顆按鈕拖曳到書籤列即可安裝。在任何網頁點一下書籤啟用,再點一次即關閉(或按 Esc)。

通用擷取

找記錄集

  • 啟用後,游標移動時橘色虛線即時預覽目前指到的元素
  • 左鍵:標紅框(上限 2,框選兩個「資料意義上同層級」的元素);再點一次取消,右鍵也可取消。與現有紅框巢狀會被拒絕
  • 紅框滿 2 後自動以綠框標出共同祖先、產生查詢判斷式,並以藍框標出所有命中元素
  • 下方工具列:⬆⬇ 逐層移動綠框(點擊頁面上的共同祖先亦可直接跳層);判斷式各節點為 pill,點擊循環切換 predicate(中間節點 [n]↔[*],最末節點 [n]→裸標籤→[*]);無同名 sibling 的節點為 disabled
  • 複製查詢式:綠框絕對 XPath + 判斷式;抽取文字:藍框元素直屬文字一行一筆
  • ◐ 切換工具的亮/暗主題(預設自動取頁面的相反)

深入擷取(多欄位)

當資料深埋巢狀結構、抽取文字抓不到東西時,按 深入 開啟 modal。以第一個紅框為樣本列,列出其中所有可擷取的內容;設計細節見 field-extraction-design.md。

  • UI 模式:樹狀核取方塊(左鍵勾選),下方「分欄」尺點擊間隙插入/移除斷點 → 每一段即一個欄位。右側徽章顯示命中率(超過 50 筆記錄時為取樣診斷,擷取仍為全部)
  • Script 模式:一欄一條 expression。無前綴 = XPath,$ 前綴 = CSS,= 前綴 = JS(el 為當下記錄)。可由 UI 模式一鍵轉移後手動放寬
  • Raw:所有藍框的 outerHTML 原封不動
  • 輸出以 \t 分欄、\n 分列;值內的控制字元逃逸成 Unicode Control Pictures(␊ ␉),反斜線與 & 完全不動

注意:極少數網站的 CSP 會擋 bookmarklet 或禁用 = JS 列(選擇式列不受影響);iframe 內容與 SVG/命名空間元素標不到
